# AGENTS.md — PromptForge AI

## What this is

Next.js 16 app (App Router) that compiles user prompts into optimized prompts for specific AI image models (Midjourney, FLUX, DALL-E 3, Stable Diffusion). Uses Google Gemini API with a deterministic fallback when no API key is configured.

## Commands

```bash
pnpm dev          # Dev server (Turbopack, port 3000)
pnpm build        # Production build
pnpm start        # Serve production build
pnpm lint         # ESLint (next/core-web-vitals + typescript)
```

No test suite. No typecheck script — run `npx tsc --noEmit` manually.

Package manager is **pnpm** (`pnpm-lock.yaml` present).

## Environment setup

`.env` exists with placeholder values. `.env.local` is what Next.js actually reads (gitignored). Required vars:

- `DATABASE_URL` — PostgreSQL connection string (Supabase pooler)
- `DIRECT_URL` — Direct PostgreSQL connection (for Prisma migrations)
- `GOOGLE_AI_KEY` — Google Gemini API key (optional; without it, compiler uses deterministic fallback)
- `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` — used by `src/utils/supabase.ts` (browser client)

## Prisma

Schema at `prisma/schema.prisma`. After changing it:

```bash
npx prisma generate   # Regenerate client
npx prisma db push    # Push schema to database (no migration files yet)
```

Two Prisma client locations:
- `src/lib/supabase.ts` — singleton (use this one)
- `src/actions.ts` — creates its own `new PrismaClient()` (inconsistency)

## Project structure

```
src/
  app/
    page.tsx           # Landing/home page
    layout.tsx         # Root layout (Geist fonts, dark theme)
    globals.css        # Tailwind v4 + CSS custom properties
    sign-in/page.tsx   # Sign-in page (client component)
    api/compiler/      # POST endpoint (nodejs runtime)
  register/page.tsx    # Sign-up page (outside app/, uses server action)
  actions.ts           # Server action: signUpUser
  components/          # CompilerPlayground, Navbar, Footer
  lib/
    compiler.ts        # Core logic: rate limiting, style tokens, Gemini API, deterministic fallback
    supabase.ts        # Prisma client singleton
  utils/supabase.ts    # Supabase browser client (@supabase/ssr)
  types/index.ts       # TargetModel, StyleToken, CompilerRequest/Response types
prisma/schema.prisma   # Organization, User, BrandStyle, PromptTemplate models
```

## Key conventions

- **Tailwind CSS v4** — uses `@tailwindcss/postcss` plugin (no `tailwind.config.*` file). Theme tokens defined as CSS custom properties in `globals.css` and bridged via `@theme inline`.
- **Path alias**: `@/*` maps to `./src/*`.
- **No test files or test framework** configured. If adding tests, confirm with the user first.
- **Dark theme only** — background `#09090b`, accent `#8b5cf6` (violet). All styling uses these CSS variables.
- **Turbopack** enabled in `next.config.ts`.
- ESLint uses flat config (`eslint.config.mjs`) with `eslint-config-next` presets.
- **API route** (`src/app/api/compiler/route.ts`) runs on **nodejs runtime** (not edge — see `export const runtime = "nodejs"`).
- `env1.ts` is auto-generated by Next.js — do not edit.
- `pnpm-workspace.yaml` allows builds for `@prisma/client`, `@prisma/engines`, `prisma`, `sharp`, and `unrs-resolver`.
