# AGENTS.md — PromptForge AI

## What this is

Next.js 16 app (App Router) that compiles user prompts into optimized prompts for specific AI models (Midjourney, FLUX, DALL-E 3, Stable Diffusion, OpenAI, Anthropic, Google). Uses Google Gemini API with a deterministic fallback when no API key is configured. Includes Supabase auth, Stripe payments, and a prompt history/saving system.

## Commands

```bash
pnpm dev          # Dev server (Turbopack, port 3000)
pnpm build        # Production build
pnpm start        # Serve production build
pnpm lint         # ESLint (next/core-web-vitals + typescript)
```

No test suite. No typecheck script — run `npx tsc --noEmit` manually.

Package manager is **pnpm** (`pnpm-lock.yaml` present).

## Environment setup

`.env` exists with placeholder values. `.env.local` is what Next.js actually reads (gitignored). Required vars:

- `DATABASE_URL` — PostgreSQL connection string (Supabase pooler)
- `DIRECT_URL` — Direct PostgreSQL connection (for Prisma migrations)
- `GOOGLE_AI_KEY` — Google Gemini API key (optional; without it, compiler uses deterministic fallback)
- `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` — used by `src/utils/supabase.ts` (browser client)
- `STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET` / `NEXT_PUBLIC_STRIPE_PRO_PRICE_ID` — Stripe integration

## Prisma

Schema at `prisma/schema.prisma`. After changing it:

```bash
npx prisma generate   # Regenerate client
npx prisma db push    # Push schema to database (no migration files yet)
```

Multiple Prisma client locations (inconsistency):
- `src/lib/supabase.ts` — singleton (use this one for most cases)
- `src/actions.ts` — creates its own `new PrismaClient()`
- `src/app/api/webhooks/stripe/route.ts` — creates its own `new PrismaClient()`

## Key conventions

- **Tailwind CSS v4** — uses `@tailwindcss/postcss` plugin (no `tailwind.config.*` file). Theme tokens defined as CSS custom properties in `globals.css` and bridged via `@theme inline`.
- **Path alias**: `@/*` maps to `./src/*`.
- **No test files or test framework** configured. If adding tests, confirm with the user first.
- **Dark theme only** — background `#09090b`, accent `#8b5cf6` (violet). All styling uses these CSS variables.
- **Turbopack** enabled in `next.config.ts`.
- ESLint uses flat config (`eslint.config.mjs`) with `eslint-config-next` presets.
- **API routes** run on **nodejs runtime** (not edge — see `export const runtime = "nodejs"`).
- `env1.ts` is auto-generated by Next.js — do not edit.
- `pnpm-workspace.yaml` allows builds for `@prisma/client`, `@prisma/engines`, `prisma`, `sharp`, and `unrs-resolver`.

## Auth flow

- Supabase handles authentication (email/password, OAuth)
- `src/middleware.ts` protects routes (redirects unauthenticated users to `/sign-in`)
- `src/lib/auth-provider.tsx` provides client-side auth context
- Registration creates both a Supabase auth user and a database user + organization
- Unauthenticated users can still use the compiler (guest mode, no rate limiting by plan)

## API rate limiting

- `src/lib/compiler.ts`: IP-based rate limiting (30 requests per 60 seconds)
- `src/app/api/compiler/limits.ts`: Plan-based compilation limits (FREE: 10/month, PRO/ENTERPRISE: unlimited)

## Important patterns

- **Gemini API calls** use `fetch()` directly to `generativelanguage.googleapis.com` (no SDK)
- **Stripe webhooks** require raw body for signature verification (handled in `src/app/api/webhooks/stripe/route.ts`)
- **Vision API** (`/api/vision/analyze`) accepts base64 data URLs, validates image type/size, uses Gemini for analysis
- **Prompt saving** (`/api/prompts`) stores prompts with models, styles, and variables in `SavedPrompt` table
- **Dashboard** shows plan-specific UI and prompt history
